# Week 7 Exit Ticket

Answer independently.

1. Identify one genuine alternative design decision you considered today.
2. Explain why it is meaningfully different from your original design.
3. Identify one mobile/tablet compatibility decision you made.
4. Identify one piece of technical documentation you created.
5. Identify one copyright or data-protection consideration relevant to your planned website.
6. Complete this sentence:

**The technical/design decision I am most confident in is... because it supports the requirement... by...**

## Confidence check

Rate yourself 1–5 for each:

- I can create a genuine alternative design.
- I can explain responsive design decisions.
- I can plan an interactive feature using pseudocode/flowchart logic.
- I can record asset/legal considerations.
- I can connect a technical decision to a client/user requirement.
