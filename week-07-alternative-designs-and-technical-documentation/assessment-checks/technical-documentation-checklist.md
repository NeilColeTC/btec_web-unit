# Week 7 Technical Documentation Checklist

Use this before Week 8 design review.

## Alternative design evidence

- [ ] I have retained my original design.
- [ ] I have produced at least one meaningful alternative.
- [ ] My alternative changes more than colour/font alone.
- [ ] I have compared alternatives against audience/user needs.
- [ ] I have compared alternatives against client requirements.
- [ ] I have recorded strengths, limitations or trade-offs.

## Responsive compatibility

- [ ] I have considered desktop presentation.
- [ ] I have considered tablet presentation.
- [ ] I have considered mobile presentation.
- [ ] I have identified changes to navigation/layout/content priority.
- [ ] I have explained why responsive changes are appropriate.

## SEO planning

- [ ] I have considered meaningful page titles/headings.
- [ ] I have identified relevant content/keywords without keyword stuffing.
- [ ] I have considered metadata and meaningful link/image text.

## Asset planning

- [ ] I have identified the assets I need.
- [ ] I have recorded whether each asset is original or externally sourced.
- [ ] I have recorded source/creator information where required.
- [ ] I have considered permission/licensing/copyright.
- [ ] I have considered suitable file types/optimisation.

## Client-side scripting documentation

- [ ] I have identified at least one planned interactive feature.
- [ ] I have described its intended behaviour.
- [ ] I have written pseudocode for the logic.
- [ ] I have created an appropriate flowchart.
- [ ] My logic matches something I genuinely intend to implement.

## Legal / ethical considerations

- [ ] I have considered copyright for planned assets.
- [ ] I have considered data protection for personal information collected by the site.
- [ ] I have questioned whether form fields are necessary for the stated purpose.

## Traceability and justification

- [ ] Important technical/design choices link back to requirements.
- [ ] I can explain why I selected one alternative over another.
- [ ] My documentation is clear enough for another person to review in Week 8.
