# Week 3 Lesson Plan – Creativity, Media, SEO and Performance

**W/B:** 21 September 2026  
**Duration:** 3 hours  
**Specification focus:** A1–A2  
**Assessment preparation:** A.P1 progressing towards A.M1

## Learning outcomes

Learners will be able to:

1. Explain how position, colour, contrast and size affect visual communication.
2. Judge the appropriateness of media for audience and purpose.
3. Explain how creativity and innovation influence website effectiveness.
4. Explain the purpose of SEO, indexing, meta tags, keywords and regular updates.
5. Distinguish client-side from server-side processing.
6. Explain why browser compliance matters.
7. Apply these ideas to BBC/Amazon evidence.
8. Develop a comparison into an analytical paragraph.

## Key terminology

position, colour, contrast, size, media, appropriateness, creativity, innovation, unconventional layout, white space, golden ratio, SEO, indexing, meta tag, keyword, crawling, client-side, server-side, browser compliance, performance, analysis.

## Teacher modelling

Use a non-assessment website and model the progression:

1. **Evidence:** identify a specific feature.
2. **Effect:** explain what it changes for the user.
3. **Reason:** explain why that effect occurs.
4. **Audience/purpose:** connect the feature to intended use.
5. **Performance/visibility:** where relevant, explain technical or SEO implications.

Example structure:

> The page uses a large high-contrast hero image to direct attention towards the main call to action. This supports rapid visual hierarchy for first-time visitors, but the file must be appropriately optimised because an unnecessarily large image could increase download time.

Do not convert this into BBC/Amazon wording for learners.

## Adaptive teaching

### Support

- provide a visual glossary for colour, contrast, hierarchy and media
- use pre-selected screenshots where the relevant feature is obvious
- provide sentence starters such as “This is appropriate because…”, “This may reduce performance because…”, and “This supports the audience by…”
- use client/server sorting cards before written explanation
- allow paired verbal rehearsal

### Stretch

- ask learners to identify competing design goals
- evaluate whether creativity has reduced intuitiveness
- distinguish discoverability from ranking guarantees
- ask learners to explain indirect organisational consequences of poor SEO or compatibility
- require multi-step causal reasoning

## English and mathematics

**English:** analytical connectives, cause/effect reasoning, technical vocabulary, comparative structures.

**Mathematics:** proportion, relative size, spacing and the introductory idea of the golden ratio. Avoid presenting the golden ratio as a universal rule of good design.

## EDI / British Values / employability

Discuss how colour and media choices affect different users and why contrast and clarity support inclusion. Encourage respectful critique of unconventional design. Link SEO, compatibility and performance decisions to professional accountability and client requirements.

## Misconceptions to anticipate

- more media always makes a site better
- creativity means breaking usability conventions
- SEO guarantees first place in search results
- meta tags are visible page content
- keywords should simply be repeated as often as possible
- all scripts run in the browser
- all scripts run on the server
- if a site works in one browser it will work identically everywhere
- visual quality and technical performance are unrelated

## Assessment boundary

BBC and Amazon are assessment comparators. Do not supply completed analyses. Model process and structure with other websites, then require learners to select and explain their own evidence.

## After the lesson

Identify learners who can name features but cannot explain effects, and learners who confuse SEO with paid advertising or client-side with server-side processing. Revisit these in Week 4 retrieval.
