# Week 3 Activity – Media Appropriateness

## Purpose

Judge whether media choices are suitable for a website's audience, purpose and technical context.

For each scenario, identify:

- the media being used
- one possible benefit
- one possible drawback
- whether it is appropriate
- what you would change, if anything

## Scenario 1 – College homepage

A college homepage uses a full-screen autoplay video showing campus life. The video is high resolution and begins downloading immediately on mobile devices.

Consider:
- first impressions
- mobile users
- data usage
- load time
- accessibility

## Scenario 2 – Online retailer

A product page contains eight clear product images, zoom functionality and one short demonstration video.

Consider:
- buying decisions
- product comparison
- page weight
- usefulness of each media item

## Scenario 3 – News website

Every story contains a large animated banner above the headline, even when the animation is unrelated to the story.

Consider:
- attention
- distraction
- relevance
- readability
- performance

## Scenario 4 – Accessibility information page

Important instructions are presented only as an infographic image. There is no equivalent text content.

Consider:
- users of assistive technology
- readability
- alternative text
- whether the information is available in another form

## Scenario 5 – Game promotional website

The homepage uses interactive animation, video trailers and large character artwork. The target audience is experienced gamers interested in a new release.

Consider:
- audience expectation
- immersion
- performance
- device compatibility

## Extension

Choose one real website and identify one media choice that creates a genuine trade-off between visual impact and technical performance. Explain the trade-off in a paragraph.
