# Week 3 – Creativity, Media, SEO and Performance

**W/B:** 21 September 2026  
**Duration:** 3 hours  
**Specification:** A1–A2  
**Assessment preparation:** A.P1 progressing towards A.M1

## Curriculum intent

Develop learners' understanding of how creative choices, media use, search engine optimisation and technical factors contribute to the effectiveness of websites.

Week 3 extends the analytical process from Weeks 1–2:

**feature → design principle → effect → audience/purpose → performance/visibility implication**

Learners should begin moving beyond comparison into explanation and early analysis by linking design decisions to both user experience and website performance.

## Learning outcomes

By the end of the session learners will be able to:

1. Explain how position, colour, contrast and size influence visual communication.
2. Judge whether media is appropriate for audience, purpose and context.
3. Explain how creativity and innovation can improve or weaken website effectiveness.
4. Describe the golden ratio as a possible design approach and explain its limitations.
5. Explain the purpose of SEO, indexing, meta tags, keywords and regular updates.
6. Distinguish between client-side and server-side processing at an introductory level.
7. Explain why browser compliance matters.
8. Apply these ideas to comparative analysis of BBC and Amazon.
9. Develop writing from simple comparison towards analysis.

## Adaptive teaching

### Support

- visual examples for terminology
- colour/contrast and media prompts
- SEO vocabulary grid
- client-side/server-side sorting cards
- paragraph scaffold: evidence → effect → reason → audience/purpose
- paired oral rehearsal before written analysis

### Stretch

- evaluate trade-offs between creativity and usability
- explain why visually impressive media can reduce performance
- distinguish visibility from ranking
- analyse how the same feature can improve one user goal while harming another
- connect technical performance to commercial or organisational impact
