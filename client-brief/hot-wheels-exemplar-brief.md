# Hot Wheels – Exemplar Client Brief

## Context

Hot Wheels is a fictional creative technology organisation used solely as a teaching exemplar for website development.

The organisation would like a small public-facing website that explains what it does, presents examples of its work and gives prospective customers a way to make an enquiry.

This brief exists so that learners can see how website-development decisions can be related to requirements. It is deliberately different from the assessed Hot Beans Web scenario.

## Purpose

The website should:

- introduce the organisation clearly
- explain the types of services it offers
- show examples or imagery relating to its work
- allow users to make a general enquiry
- work effectively across common desktop, tablet and mobile screen sizes

## Intended audience

The main audience is adults and small organisations looking for information about digital/web services.

Users may have different levels of technical knowledge and may access the website using different devices.

## Required content

The website should include:

- a home page introducing the organisation
- information about the organisation and its approach
- information about example services
- a gallery or examples section
- a contact/enquiry page
- consistent navigation between pages

## Design expectations

The website should be:

- clear and easy to navigate
- visually consistent
- readable
- responsive
- appropriate for the intended audience
- mindful of accessibility
- based on valid, meaningful HTML structure

## Interactivity

The final exemplar may include suitable client-side interactivity where it improves usability or demonstrates a purposeful feature.

The developer should be able to explain why JavaScript is appropriate for a feature rather than adding scripting simply because it is available.

## Constraints

- The exemplar is a static client-side website.
- The enquiry form is demonstrative and does not transmit or store personal data.
- The site should remain understandable enough for learners to inspect its HTML, CSS and JavaScript.
- Features should demonstrate transferable techniques rather than imitate the assessed Hot Beans Web solution.

## Development expectation

The website should be developed progressively so that changes between HTML structure, responsive presentation and JavaScript-enhanced behaviour can be compared.

Testing and feedback should be used to identify genuine refinements. Before-and-after evidence should be retained where an optimisation is demonstrated.
