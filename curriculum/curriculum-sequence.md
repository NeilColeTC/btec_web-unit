# Unit 6 Curriculum Sequence

This document provides the high-level teaching sequence for the 17-week delivery of **Pearson BTEC Level 3 Unit 6: Website Development**.

The weekly folders remain the detailed source of lesson plans, slides, learner activities, assessment checks and teacher guidance.

## Curriculum model

The sequence is deliberately cumulative:

**analyse → design → review → implement → test → optimise → evaluate → finalise**

The existing Hot Wheels website is used as a staged teaching exemplar. It demonstrates transferable techniques and development methodology without becoming starter code for the assessed Hot Beans Web solution.

## Phase structure

### Phase 1 — Understand existing websites: Weeks 1–4

Learners develop the language and reasoning needed to compare, analyse and evaluate websites. By Week 4 the taught Learning Aim A content is consolidated through the progression **compare → analyse → evaluate**.

### Phase 2 — Design from a client brief: Weeks 5–8

Learners move from analysis into independent vocational design. The important thread is **brief → requirements → designs → alternatives → review → justified refinement**.

### Phase 3 — Implement purposefully: Weeks 9–12

Learners translate reviewed designs into a working website. The Hot Wheels stages support teaching of separation of concerns:

- Stage 1 — HTML structure and meaning
- Stage 2 — CSS presentation and responsive layout
- Stage 3 — JavaScript behaviour and refinement

Learners then transfer the techniques into their own solution rather than reproducing the exemplar.

### Phase 4 — Test and optimise: Weeks 13–14

Learners use the evidence cycle:

**requirement → test → evidence → issue → change → retest → judgement**

Testing failures are retained as valuable development evidence rather than hidden.

### Phase 5 — Evaluate and close the project: Weeks 15–17

Learners synthesise the project as a complete design-development-review process. Evaluation is based on evidence, limitations and trade-offs. Finalisation prioritises stability, evidence integrity and submission readiness over late feature additions.

## Recurring pedagogical principles

Across all weeks:

- retrieval practice revisits prior learning;
- teacher modelling uses neutral or exemplar contexts where complete assessed answers would create assessment risk;
- learners are repeatedly required to connect decisions to audience, purpose and client requirements;
- practical work is followed by explanation and evidence capture;
- adaptive support reduces cognitive load without removing learner decision making;
- stretch focuses on trade-offs, alternatives, justification and evidence quality;
- assessment evidence must remain the learner's own.

## Exemplar boundary

The staged Hot Wheels site is a **teaching exemplar**. Learners may inspect, run, experiment with and critique it. Their assessed Hot Beans design, content, code, testing, optimisation and evaluation must arise from their own interpretation of the approved client brief.
