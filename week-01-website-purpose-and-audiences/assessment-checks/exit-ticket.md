# Week 1 Exit Ticket

Complete independently.

Choose either BBC or Amazon and answer the following.

1. Is the website primarily content-based, product/service-based, or mixed? Explain briefly.
2. What is one important purpose of the website?
3. Identify one important target-audience group.
4. Give one requirement that audience is likely to have.
5. Identify one website feature that helps meet that requirement.
6. Explain **why** the feature is suitable for that audience and purpose.
