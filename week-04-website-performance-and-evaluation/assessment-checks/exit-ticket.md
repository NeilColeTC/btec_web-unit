# Week 4 Exit Ticket

Complete independently.

1. Name one server-side performance factor and explain its effect.
2. Name one client-side performance factor and explain its effect.
3. Give one example of a design-performance trade-off.
4. What is the difference between analysis and evaluation?
5. Write one sentence that reaches a supported evaluative judgement about a website feature.
6. Which Learning Aim A criterion do you currently feel least confident about: A.P1, A.M1 or A.D1? Explain why.

## Teacher use

Use responses to identify learners who still:

- confuse server-side and client-side factors
- describe rather than analyse
- list strengths/weaknesses without judging significance
- make unsupported claims about organisational impact
- need targeted support before Assignment 1 submission
