## Slide 6 – What does website performance mean?
Performance is about how effectively a website responds and delivers its content and functionality to users.

It can be affected by:

- infrastructure
- network conditions
- file choices
- browser/device capability
- scripts and interactivity

## Slide 7 – Server-side factors
The specification highlights:

- bandwidth availability
- number of hits
- file types

Ask: how could each influence what users experience?

## Slide 8 – Bandwidth
Bandwidth is the amount of data that can be transferred over a connection in a given period.

Consider:

- server capacity
- concurrent users
- large files
- peak demand

## Slide 9 – Number of hits
A heavily used website may receive many simultaneous requests.

Possible effects:

- slower response
- server load
- delayed content delivery
- failures if capacity is exceeded

## Slide 10 – File types
File choice affects:

- file size
- quality
- browser support
- download time
- suitability for purpose

A technically smaller file is not automatically the best choice.

## Slide 11 – Client-side factors
The specification highlights:

- upload/download speed
- browser
- cache memory
- processor speed
- interactivity

## Slide 12 – Upload and download speed
Different users may experience the same website differently.

Why?

- home broadband
- mobile data
- congested networks
- geographic location
- shared connections

## Slide 13 – Browser
Browsers can differ in:

- supported features
- rendering behaviour
- JavaScript support
- accessibility implementation

Compatibility matters.

## Slide 14 – Cache memory
Caching can reduce repeated downloads by storing resources locally.

Benefits:

- faster repeat visits
- reduced data transfer

Possible issue:

- users may sometimes see older cached content.

## Slide 15 – Processor speed
Complex pages can require more client-side processing.

Potentially demanding features include:

- animation
- large scripts
- effects
- complex interactions

## Slide 16 – Interactivity
Interactivity can improve usability and engagement, but it can also add complexity.

Evaluate it by asking:

- does it help the user?
- what does it cost in performance?
- does it work across devices/browsers?

## Slide 17 – Performance is interconnected
Example:

large video → larger transfer → slower download on poor connection → delayed page use → possible abandonment

This is analysis because it explains a chain of consequences.

## Slide 18 – Design-performance trade-offs
Consider:

- high-resolution images
- video backgrounds
- animations
- custom fonts
- large JavaScript libraries

What value does each add? What cost might it introduce?

## Slide 22 – Organisational impact
Website effectiveness can influence:

- reputation
- sales/conversions
- customer service
- user trust
- staff workload
- support costs
- accessibility/inclusion

## Slide 23 – Positive organisational outcomes
Examples may include:

- easier access to services
- improved customer satisfaction
- stronger brand perception
- increased sales or engagement
- reduced support burden

## Slide 24 – Negative organisational outcomes
Examples may include:

- abandoned purchases
- complaints
- reputational damage
- lost users
- accessibility exclusion
- increased support demand

## Slide 25 – Compare
Comparison identifies similarities and differences.

Example structure:

“Both sites use…, whereas…”

Useful, but not enough for Merit or Distinction by itself.

## Slide 26 – Analyse
Analysis explains how and why.

A useful chain:

**evidence → effect → audience/purpose/performance consequence**

## Slide 27 – Evaluate
Evaluation reaches a supported judgement.

A useful chain:

**evidence → effect → consequence → limitation/trade-off → judgement**

## Slide 28 – Weak versus stronger evaluation
Weak:

“The website is good because it is easy to use.”

Stronger:

- identify evidence
- explain why it supports the user
- acknowledge any limitation
- judge its effectiveness in context

## Slide 29 – Evaluation language
Useful phrases:

- this is effective because…
- however…
- a limitation is…
- this matters particularly for…
- overall…
- on balance…
- in this context…
