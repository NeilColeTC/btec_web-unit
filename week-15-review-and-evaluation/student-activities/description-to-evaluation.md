# Description → Evaluation Workshop

## Purpose

Practise upgrading weak statements into evidence-based evaluation.

Use the progression:

**describe → explain → analyse → evaluate**

---

## Task 1 – Classify the statement

Label each statement D, E, A or V.

1. “The website uses an application form.”
2. “The form allows users to provide the information needed for an application.”
3. “Required-field validation helps prevent incomplete submissions and gives users immediate feedback.”
4. “The validation was effective for the tested inputs because normal, boundary and erroneous tests produced the expected messages; however, the solution remains client-side only, so a production system would still require server-side validation.”
5. “The pages use the same colour scheme.”
6. “Consistent colour and typography make the pages feel related.”
7. “Keeping the same heading hierarchy and navigation styling reduces the amount users need to relearn when moving between pages.”
8. “The consistency supports efficient navigation for the intended audience, although one page contains denser content and would benefit from stronger visual grouping.”

## Task 3 – Add a limitation

Take one of your improved statements and add a credible limitation.

> Although…

Explain why identifying a limitation can make an evaluation stronger rather than weaker.

---

## Task 4 – Add an alternative

For the same area, identify one realistic alternative approach.

> An alternative would have been…

## Task 5 – Reach a judgement

Finish with:

> On balance, the current approach was / was not appropriate because…

Your judgement must use evidence from your own project.

## Self-check
