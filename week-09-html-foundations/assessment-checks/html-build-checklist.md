# Week 9 – HTML Build Checklist

Use this as a formative check while beginning your own implementation.

## Document structure

- [ ] Each HTML file has `<!DOCTYPE html>`.
- [ ] Each page has `<html lang="en">` or another appropriate language value.
- [ ] Character encoding is declared.
- [ ] Viewport metadata is present.
- [ ] Each page has an accurate, meaningful `<title>`.
- [ ] Visible content is inside `<body>`.

## Semantic structure

- [ ] I use semantic elements where they match the meaning of the content.
- [ ] My main content is inside `<main>`.
- [ ] Navigation is identifiable as navigation.
- [ ] Heading levels reflect content hierarchy rather than desired font size.
- [ ] I have not added unnecessary semantic elements simply to increase tag variety.

## Navigation and links

- [ ] Required pages exist according to my reviewed design.
- [ ] Relative links point to the correct files.
- [ ] Navigation is consistent where appropriate.
- [ ] I have clicked every current navigation link to test it.
- [ ] Link text communicates the likely destination.

## Images and media

- [ ] Image paths are correct.
- [ ] Informative images have meaningful alternative text.
- [ ] Decorative images are handled appropriately.
- [ ] Images used relate to my own design/content rather than being copied from Hot Wheels.

## Forms, if currently implemented

- [ ] Each control has an appropriate label.
- [ ] Input types match the data requested.
- [ ] Related controls are grouped where appropriate.
- [ ] Required fields are identified appropriately.
- [ ] I understand whether my form currently processes data or only demonstrates an interface.

## Independence and traceability

- [ ] My page structure follows my reviewed design evidence.
- [ ] I can explain why each current page exists.
- [ ] I can explain at least three semantic HTML decisions.
- [ ] I have not renamed/copied the Hot Wheels exemplar as my assessed project.
- [ ] I have recorded at least one issue found and how I fixed/tested it.
