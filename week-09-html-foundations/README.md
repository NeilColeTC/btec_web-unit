# Week 9 – HTML Foundations

**W/B:** 09 November 2026  
**Duration:** 3 hours  
**Specification focus:** C2 – Developing a website using suitable tools and techniques  
**Assessment preparation:** C.P4, C.P5

## Curriculum intent

Week 9 begins practical implementation. Learners move from reviewed design documentation into HTML structure while using the existing **Hot Wheels Stage 1 exemplar** as an object to investigate rather than a template to rename.

The central progression is:

**design intention → semantic structure → content hierarchy → navigation → media/forms → test → explain**

The lesson deliberately separates **structure/content** from later presentation and behaviour. Learners should understand that good HTML provides meaningful document structure before CSS and JavaScript are added.

## Learning outcomes

By the end of the session learners will be able to:

1. Explain the responsibilities of HTML within a website.
2. Build a valid basic HTML5 document structure.
3. Use headings, paragraphs, lists, links and images appropriately.
4. Use semantic elements including `header`, `nav`, `main`, `section`, `article` and `footer`.
5. Explain the purpose of metadata, page titles and viewport settings.
6. Create consistent relative navigation between multiple pages.
7. Use meaningful alternative text for informative images.
8. Recognise accessible form structure using labels, fieldsets and suitable input types.
9. Compare their own HTML decisions with the Hot Wheels Stage 1 exemplar without copying the assessed solution.

## Adaptive teaching

### Support

- provide an empty HTML5 skeleton with placeholders rather than finished page content
- use tag-purpose matching cards
- trace relative paths visually using a folder diagram
- pair-program short experiments before independent work
- provide a semantic-element decision guide

### Stretch

Ask learners to:

- justify semantic choices rather than using generic `div` elements
- inspect document outline and heading hierarchy
- critique when `section` or `article` is appropriate
- investigate form input types and built-in browser validation
- identify accessibility already achieved before CSS or JavaScript exists

## Assessment boundary

Hot Wheels is a worked teaching exemplar. Learners may inspect, run and modify temporary copies while learning, but their assessed Hot Beans implementation must follow their own reviewed design decisions, content structure and technical choices.
