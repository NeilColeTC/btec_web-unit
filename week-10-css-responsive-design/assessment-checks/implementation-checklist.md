# Week 10 CSS Implementation Checklist

Use this as a formative check of your own website development.

## Stylesheet structure

- [ ] My pages link to an external stylesheet.
- [ ] Shared styles are reused rather than duplicated unnecessarily.
- [ ] My CSS syntax is valid and consistently formatted.
- [ ] I can explain the purpose of the main selectors I have written.

## Visual system

- [ ] Typography is readable and consistent.
- [ ] Colour choices reflect my reviewed design.
- [ ] Spacing is deliberate and reasonably consistent.
- [ ] Page width/content width is controlled appropriately.
- [ ] I use reusable values where this improves maintainability.

## Layout

- [ ] Navigation is usable and visually clear.
- [ ] I have selected Flexbox, Grid or another layout method for a reason.
- [ ] Layout remains understandable when content changes or wraps.
- [ ] I can explain why my chosen technique suits the content.

## Responsive behaviour

- [ ] Images do not overflow their containers.
- [ ] I have tested at multiple viewport widths.
- [ ] I identified where the layout begins to fail or become crowded.
- [ ] Responsive rules address genuine layout problems.
- [ ] I have not copied Stage 2 breakpoint values without justification.
- [ ] Text remains readable on narrower screens.
- [ ] Navigation remains usable on narrower screens.
- [ ] Forms/controls remain usable on narrower screens where relevant.

## Accessibility

- [ ] Keyboard focus is visible on interactive elements.
- [ ] Hover styling is not the only indication of interaction.
- [ ] Text/background contrast has been considered.
- [ ] I have not removed semantic HTML to achieve visual styling.

## Design traceability

- [ ] My CSS reflects my own reviewed design rather than the Hot Wheels visual design.
- [ ] I can link major presentation decisions back to my design documentation.
- [ ] I can explain at least one CSS decision in terms of user need or purpose.
- [ ] I have recorded any implementation deviation from my original design and why it was needed.
