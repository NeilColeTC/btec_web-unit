# Client Brief

Place the formal website scenario/client requirements used for the unit here.

Learners should use this folder as the source of truth when judging the exemplar. The exemplar is intentionally not a perfect match for every requirement.

## Learner questions

1. Who is the target audience?
2. What is the main purpose of the website?
3. Which pages and features are explicitly required?
4. What content must appear on each page?
5. What visual style would be appropriate?
6. What accessibility and usability considerations are relevant?
7. Which aspects of the exemplar would need changing to satisfy the brief?
