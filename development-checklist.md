# Website Development Checklist

## Before coding
- Identify the client and target audience.
- Extract explicit and implied requirements.
- Produce a site map.
- Produce suitable wireframes.
- Plan content and assets.

## During development
- Use semantic HTML.
- Keep navigation consistent.
- Use external CSS.
- Test responsive layouts regularly.
- Optimise and describe images appropriately.
- Keep code readable and organised.
- Check accessibility as features are added.

## Before submission/evaluation
- Validate HTML and CSS.
- Test all links.
- Test forms and interactive features.
- Test multiple viewport sizes.
- Test keyboard navigation.
- Compare the result with the client brief.
- Record defects, fixes and improvements.
