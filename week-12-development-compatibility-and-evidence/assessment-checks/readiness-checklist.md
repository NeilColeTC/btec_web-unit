# Week 12 – Development Readiness Checklist

Use this at the end of the session before moving into formal testing.

## Core implementation

- [ ] All required pages exist.
- [ ] Navigation works consistently across the site.
- [ ] Relative links and asset paths are correct.
- [ ] External CSS is connected to all relevant pages.
- [ ] Required JavaScript is connected and functioning.
- [ ] Main content broadly matches the reviewed design.
- [ ] Significant design changes have a recorded reason.

## Responsive and compatibility

- [ ] Key pages have been checked at several viewport widths.
- [ ] I have looked for horizontal overflow.
- [ ] Images and cards adapt appropriately.
- [ ] Forms remain usable at narrow widths.
- [ ] I have tested in more than one browser where available.
- [ ] I have recorded at least one compatibility check.

## Accessibility and usability

- [ ] Keyboard focus is visible.
- [ ] Navigation and controls can be reached by keyboard.
- [ ] Images have appropriate alternative text where needed.
- [ ] Form controls have suitable labels.
- [ ] Dynamic controls communicate state appropriately.

## Development evidence

- [ ] I have preserved code/version evidence.
- [ ] I have at least one genuine defect/fix/retest record.
- [ ] I have before/after evidence for an important change.
- [ ] I can trace major requirements to implemented features.
- [ ] I know which gaps remain before formal testing.
