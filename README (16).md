# Stage 2 — Responsive Design

## Purpose

This stage builds on the HTML foundation by introducing a coherent visual design and responsive layout.

## Expected development

- external stylesheet organised into logical sections
- consistent typography, spacing and visual hierarchy
- reusable navigation/header/footer treatment
- Flexbox and/or Grid for layout
- responsive images
- mobile-first or clearly justified responsive breakpoints
- visible keyboard focus and usable interactive elements
- comparison against wireframes and client requirements

## Learner challenge

Do not assume the exemplar's visual choices are correct for the client. Identify at least three design decisions you would retain, change or reject and justify each one.
