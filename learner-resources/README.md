# Learner Resources

These resources support the staged Hot Wheels teaching exemplar. Use them to understand development methods, compare techniques, plan testing and optimisation, and keep a clear boundary between learning from the exemplar and producing an independent assessed solution.

## Included resources

- `development-process.md` — a suggested development journey from investigation through evaluation.
- `technique-map.md` — where key HTML, CSS and JavaScript techniques appear in the exemplar and questions to consider before reusing them.
- `development-checklist.md` — practical checks before, during and after development.
- `testing-example.md` — a worked example showing useful testing methodology.
- `optimisation-example.md` — a worked example of evidence-led refinement and retesting.
- `assessment-boundary.md` — guidance on appropriate use of the exemplar for the assessed Hot Beans Web project.

Use these materials to transfer **knowledge, reasoning and process**, not to copy a finished solution.
