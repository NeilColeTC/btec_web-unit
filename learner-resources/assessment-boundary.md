# Exemplar and Assessment Boundary

## What the Hot Wheels repository is

The Hot Wheels website is a worked teaching exemplar showing how one website can progress through:

**HTML structure → CSS/responsive design → JavaScript/refinement → testing → optimisation**

Learners are encouraged to inspect it, experiment with it, break it, repair it and discuss the decisions behind it.

## What it is not

It is not starter code for the assessed Hot Beans Web project.

The exemplar deliberately uses a different context so that the assessed client requirements still have to be interpreted by each learner.

## Appropriate use

Learners can use the exemplar to learn techniques and processes, for example:

- how semantic HTML can structure a page
- how Flexbox and Grid can solve layout problems
- how media queries can adapt a design
- how JavaScript can respond to events
- how form input can be validated
- how testing can identify a weakness
- how a change can be justified and retested

## Independent assessed decisions

For the assessed project, the learner should make their own decisions about:

- interpretation of users and client requirements
- site structure and navigation
- visual design and alternative designs
- assets and content
- responsive behaviour
- appropriate interactive features
- original client-side scripting
- test cases and test data
- responses to feedback
- optimisation/refinements
- evaluation and recommendations

The important transfer is **knowledge and method**, not the finished Hot Wheels solution.
