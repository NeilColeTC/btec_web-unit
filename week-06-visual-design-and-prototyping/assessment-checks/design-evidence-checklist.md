# Week 6 Assessment Check – Visual Design Evidence

Use this as a formative check before progressing to Week 7.

## Site structure
- [ ] Site map includes all required content areas.
- [ ] Page hierarchy is logical.
- [ ] Navigation labels are clear and predictable.
- [ ] Key user journeys are efficient.

## Visual direction
- [ ] Mood board shows a coherent visual style.
- [ ] Colour choices are explained.
- [ ] Typography choices are explained.
- [ ] Imagery/interface references are relevant to audience and purpose.
- [ ] Accessibility has influenced visual decisions.

## Wireframes
- [ ] At least three key pages have been planned.
- [ ] Each wireframe shows clear hierarchy and navigation.
- [ ] Required client content is visible in the design set.
- [ ] Calls to action are appropriately positioned.
- [ ] At least one responsive/mobile-tablet variation has been considered.

## Annotation and traceability
- [ ] Important design choices are annotated.
- [ ] Annotations explain rather than merely label.
- [ ] Decisions are connected to client requirements and/or user needs.
- [ ] Intended effects on usability, accessibility or purpose are explained.

## Readiness for Week 7
- [ ] I can identify at least one alternative design decision I could explore.
- [ ] I know which assets will need planning.
- [ ] I know which interactive elements may require technical documentation.
- [ ] I have identified gaps that need resolving before design review.
