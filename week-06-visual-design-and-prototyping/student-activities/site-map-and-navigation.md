# Week 6 Activity – Site Map and Navigation Structure

## Purpose

Translate the client brief and Week 5 requirements into a clear website structure.

## Part 1 – Required content check

Before drawing the site map, list the content that must be represented somewhere in the site.

## Part 2 – Build the site map

Create a site map showing:
- home/start page
- all major pages
- hierarchy
- parent/child relationships
- main navigation paths
- any secondary pages

You may draw this by hand or use a digital diagramming tool.

## Part 3 – Navigation-path test

Ask a partner to follow these journeys using only your site map:

1. Find information about the company.
2. Find out what qualifications are required for a role.
3. Read about an existing trainee developer.
4. Reach the application form.
5. Find a relevant training/course link.

## Part 4 – Justify the structure

Write a short explanation covering:
- why the hierarchy is suitable for the target audience
- how important content is prioritised
- how the structure supports the site's purpose
- how the navigation remains simple and predictable

## Quality check

Before finishing, confirm that:
- every client requirement has a location
- labels are clear and user-friendly
- important content is not buried too deeply
- users can predict where to find information
- the site map could realistically guide later development
