# Week 6 Activity – Wireframe Planner

## Purpose

Create clear page-layout designs that can guide later development and demonstrate how requirements have been interpreted.

## Part 1 – Select key pages

Produce wireframes for at least three key pages. Your set should cover a range of purposes, for example:
- landing/home page
- vacancy/job information page
- trainee profile page
- course-links page
- application form page

## Part 2 – Page planning

For each page, record:

| Page | Main user goal | Required content | Main call to action | Important accessibility/usability consideration |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

## Part 3 – Draw the wireframes

Each wireframe should consider:
- header/navigation
- heading hierarchy
- content sections
- imagery/media placeholders
- buttons/links
- forms where relevant
- spacing
- footer

Do not focus on final colours or detailed graphics at this stage.

## Part 4 – Responsive version

Choose at least one page and create a mobile/tablet variation.

Explain:
- what stacks or moves
- what becomes more prominent
- what navigation changes
- how controls remain usable on touch devices
- whether any secondary content is repositioned or reduced

## Part 5 – Annotation

For each wireframe, add annotations using:

**Decision → requirement/user need → intended effect**

Aim to include:
- navigation choice
- hierarchy/layout choice
- call-to-action choice
- accessibility choice
- responsive choice

## Self-review

Ask yourself:
- Does every major design decision have a reason?
- Could another learner build this page from the wireframe?
- Does the page clearly support a user goal?
- Is the layout consistent with the rest of the site?
- Is there evidence of responsive thinking?
