# Stage 1 – HTML Structure

## Purpose

This is the first version of the Hot Wheels teaching exemplar. It demonstrates how a coherent multi-page website can be created with HTML before presentation and client-side scripting are introduced.

It is a **worked teaching example**, not starter code for the assessed Hot Beans Web website.

## What this stage demonstrates

- HTML5 document structure
- metadata and page titles
- headings and content hierarchy
- semantic `header`, `nav`, `main`, `section`, `article` and `footer` elements
- consistent multi-page navigation
- internal and external hyperlinks
- images with meaningful alternative text
- lists
- forms, labels and fieldsets
- text and email inputs
- radio buttons and checkboxes
- textarea and buttons

## Deliberately absent

There is no external CSS and no JavaScript in Stage 1. The browser's default presentation makes the separation between **structure/content** and **presentation/behaviour** visible.

Stage 2 develops these same pages using external CSS and responsive design. Stage 3 then adds purposeful JavaScript and refinement.

## Assessment boundary

Study, test and modify this exemplar while learning. For the assessed Hot Beans Web project, interpret the client brief independently and produce your own designs, content, technical decisions, code, testing and optimisation evidence.
