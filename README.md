# BTEC Web Development Teaching Exemplar

This repository is a staged teaching resource for learners developing a multi-page website from a client brief.

The aim is **not** to provide a finished website for learners to copy. Each stage demonstrates a point in the development process and deliberately leaves opportunities for learners to critique, adapt and improve the work against the client requirements.

## Structure

- `client-brief/` — project context, requirements and learner design questions.
- `stage-1-html-foundation/` — semantic HTML, page structure, navigation and placeholder content.
- `stage-2-responsive-design/` — CSS, layout, typography, responsive behaviour and visual consistency.
- `stage-3-functional-exemplar/` — refined exemplar with interaction, accessibility and testing considerations.
- `learner-resources/` — checklists, planning prompts and testing resources.
- `teacher-notes/` — suggested delivery sequence and teaching guidance.
- `shared-assets/` — common assets available to all stages.

## Suggested 3–4 week journey

### Week 1 — Requirements, planning and HTML
Analyse the client brief, identify pages/content, create a site map and wireframes, then construct semantic HTML.

### Week 2 — CSS and responsive design
Develop visual identity, layout, navigation, typography and responsive behaviour. Learners compare implementation choices with the client brief.

### Week 3 — Functionality and refinement
Add appropriate JavaScript, improve accessibility, refine content and implement functional components such as galleries or forms.

### Week 4 — Testing, evaluation and adaptation
Test across browsers/device sizes, fix defects, gather feedback and make justified improvements.

## Core teaching principle

A strong learner response should be able to explain **why** a design or development change is appropriate for the client and target audience, rather than simply reproducing exemplar code.
