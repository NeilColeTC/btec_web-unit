# JavaScript Implementation Planner

## Purpose

Plan **your own** client-side scripting from your reviewed Hot Beans design and requirements.

Do not begin with “I want to add JavaScript.” Begin with a need.

---

## 1. Requirement / user need

What requirement, usability issue or user need are you addressing?

**Evidence/source in my design documentation:**

---

## 2. Proposed behaviour

Describe what should happen from the user's point of view.

> When the user…
>
> the website should…
>
> so that…

---

## 3. Is JavaScript necessary?

Could this be achieved sufficiently using:

- semantic HTML?
- built-in browser functionality?
- CSS?

Why is JavaScript justified, if it is?

---

## 4. Event

What event(s) will trigger the behaviour?

Examples: click, submit, input, change, load, scroll.

## 8. State/data

Does the feature need to remember anything?

- [ ] no state required
- [ ] temporary page state
- [ ] persistent browser state

If persistent, what exactly will be stored and why is that appropriate?

---

## 9. Accessibility

Consider:

- keyboard operation;
- focus;
- accessible name;
- state attributes;
- error/status messages;
- behaviour without JavaScript.

What will you implement/check?
