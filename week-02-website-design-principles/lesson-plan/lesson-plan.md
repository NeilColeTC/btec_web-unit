# Week 2 Lesson Plan – Website Design Principles

**W/B:** 14 September 2026  
**Duration:** 3 hours  
**Specification focus:** A1  
**Assessment preparation:** A.P1

## Learning outcomes

Learners will be able to:

1. Define key website-design principles from the Unit 6 specification.
2. Identify examples of these principles in real websites.
3. Explain how design choices influence usability, accessibility and communication.
4. Compare the use of design principles across contrasting websites.
5. Link design decisions to intended audience and purpose.
6. Produce comparative written evidence that moves beyond simple description.

## Key terminology

usability, white space, site layout, accessibility, spacing, navigation, typography, alignment, clarity, consistency, intuitiveness, accuracy, content, media, simplicity, hierarchy, contrast, responsive design, user experience, audience, purpose.

## Teacher modelling framework

Use:

1. **Principle:** Which design principle is visible?
2. **Evidence:** What specific feature demonstrates it?
3. **Effect:** What does that feature help the user do, understand or notice?
4. **Audience:** Why is that useful for this particular user group?
5. **Purpose:** How does it support the site's intended purpose?
6. **Comparison:** Is the same principle used differently elsewhere, and why?

Avoid unsupported statements such as:

- “The website has good navigation.”
- “The colours look nice.”
- “The website is professional.”

Instead, demand observable evidence and effect.

## Adaptive teaching

### Support

- provide a glossary with visual examples
- use a reduced set of six principles first: usability, layout, navigation, typography, accessibility and consistency
- provide principle → evidence → effect sentence frames
- allow paired website exploration before independent writing
- model how to capture evidence accurately
- use a partially completed comparison grid

### Stretch

- ask learners to identify competing design priorities
- require explanation of how one feature contributes to more than one design principle
- compare desktop and mobile presentation where appropriate
- distinguish effectiveness for novice versus experienced users
- challenge learners to identify where a convention is deliberately broken and whether this is effective

## English and mathematics

**English:** precise technical vocabulary, comparative connectives, evidence-based explanation, paragraph cohesion, audience-aware communication.

**Mathematics:** proportional spacing, alignment, relative sizing, visual hierarchy and simple discussion of responsive dimensions.

## EDI / British Values / employability

Accessibility provides a direct opportunity to discuss inclusive design and differing user needs. Learners should avoid assumptions about age, ability or digital confidence. Encourage respectful peer critique based on evidence. Link design analysis to professional web-development roles where designers must justify decisions to clients and users.

## Misconceptions to anticipate

- white space must literally be white
- more content always means a better website
- accessibility is only about visual impairment
- simple design means boring design
- consistent design means every page must be identical
- attractive design automatically means usable design
- a design principle can be judged without reference to audience or purpose
- navigation means only the top menu

## Assessment boundary

Learners are developing evidence for A.P1, but detailed model answers should not be written about the two assessment comparators. Model the analytical process with another site, then support learners through questioning and structure rather than providing completed assignment wording.

## After the lesson

Review comparison work for three common gaps: missing evidence, missing audience/purpose link, and description without comparison. Use these as retrieval and feedback targets at the start of Week 3.
