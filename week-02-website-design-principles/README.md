# Week 2 – Website Design Principles

**W/B:** 14 September 2026  
**Duration:** 3 hours  
**Specification:** A1 – Purpose and principles of website products  
**Assessment preparation:** A.P1

## Curriculum intent

Develop learners' understanding of the principles used to create effective websites and move them from simply identifying visible features towards explaining how design decisions support audience and purpose.

Week 2 extends the Week 1 analytical framework:

**Website → Purpose → Audience → Design principle → Evidence → Effect**

Learners continue to use BBC and Amazon as contrasting course comparators, but teaching examples should include additional non-assessment websites so that the lesson teaches transferable analysis rather than supplying assignment-ready responses.

## Learning outcomes

By the end of the session learners will be able to:

1. Define the principal website-design terms required by Unit 6 A1.
2. Identify evidence of design principles in existing websites.
3. Explain how usability, layout, navigation, typography, accessibility and consistency influence user experience.
4. Distinguish between identifying a design feature and explaining its effect.
5. Compare how two websites use similar design principles differently for different audiences and purposes.
6. Begin producing comparative evidence appropriate to A.P1.

## Core specification content

The session focuses on the A1 principles of website design:

- usability
- white space
- site layout
- accessibility
- spacing
- navigation
- typography
- alignment
- clarity
- consistency / intuitiveness
- accuracy
- content
- media
- simplicity

Learners should also revisit target audience, intended purpose and user/client requirements from Week 1.

## Formative assessment

Use:

- retrieval questioning
- feature-to-principle matching
- live website annotation
- design-principles audit
- targeted questioning using “so what?” prompts
- comparative writing
- peer checking against A.P1 language
- retrieval quiz
- exit ticket

## Adaptive teaching

### Support

- visual glossary of design principles
- principle → evidence → effect scaffold
- sentence stems for comparison
- paired oral rehearsal before writing
- partially completed audit table
- reduce the number of principles initially while maintaining depth of explanation

### Stretch

Ask learners to:

- identify tensions between principles, such as visual richness versus simplicity
- explain why the same design choice may be effective for one audience but less effective for another
- distinguish user preference from evidence-based usability judgement
- connect several principles together in a single analytical explanation
- evaluate whether consistency can ever become restrictive

## Assessment boundary

BBC and Amazon are the planned Assignment 1 comparators, so teacher modelling should avoid providing completed comparative paragraphs about them. Use a third website for detailed modelling, then require learners to transfer the method independently to BBC and Amazon.
