# Success Criteria Workshop

A useful success criterion is **specific, observable, testable and linked to a requirement**.

## Part 1 – Improve weak criteria

Rewrite each statement so that it could be checked later.

1. The website will look professional.
2. The website will be easy to use.
3. The application form will work.
4. The site will be mobile friendly.
5. The website will be accessible.
6. The content will be good.

## Part 3 – Quality check

For each of your criteria ask:

- Can I observe or test this?
- Is it linked to a real requirement or justified user need?
- Is the wording precise enough to avoid subjective judgement?
- Will it be useful during testing and evaluation?
