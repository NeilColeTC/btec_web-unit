# Stage 1 — HTML Foundation

## Purpose

This stage represents the end of the first development milestone. The focus is structure rather than appearance.

## Expected features

- sensible folder/file structure
- multiple linked HTML pages
- semantic elements such as `header`, `nav`, `main`, `section` and `footer`
- headings in a logical hierarchy
- placeholder or draft content
- meaningful image alternative text where images are used
- working relative navigation links

## Intentionally incomplete

Visual styling, responsive layout and JavaScript functionality should be minimal or absent. Learners should be able to identify what still needs to be developed.
