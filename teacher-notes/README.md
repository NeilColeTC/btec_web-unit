# Teacher Notes

These notes support delivery of the staged Hot Wheels teaching exemplar for Pearson BTEC Level 3 Unit 6: Website Development.

The exemplar is intended to demonstrate transferable techniques and development methodology without providing a ready-made solution to the assessed Hot Beans Web project.

## Included notes

- `specification-mapping.md` — maps the exemplar to relevant Learning Aim B and C content while distinguishing teaching coverage from assessed evidence.
- `teaching-sequence.md` — suggests how to introduce HTML, CSS, JavaScript, testing and optimisation progressively before learners return to their independent assessed work.
- `assessment-boundary.md` — explains how to use the exemplar while maintaining a clear boundary around learner-authored assessment evidence.
- `github-workflow.md` — suggests ways Git and GitHub can support version history, staged development and evidence of an iterative process.

## Recommended use

Release and discuss the stages progressively rather than presenting Stage 3 as a starting template. Encourage learners to compare versions, identify why changes were made, test alternatives and justify their own choices.

Use the learner-facing materials in `../learner-resources/` alongside these notes. Asset provenance and licensing information is recorded separately in `../shared-assets/ASSET-ATTRIBUTION.md`.
