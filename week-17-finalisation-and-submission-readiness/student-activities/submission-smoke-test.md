# Submission Smoke Test

## Purpose

Test the **actual final submission copy** from a clean start. This is a release-readiness check, not a replacement for your formal testing evidence.

---

## Preparation

- [ ] Save and close the working version.
- [ ] Create/open the final submission copy.
- [ ] Confirm you know which file is the intended start/home page.
- [ ] Do not rely on files outside the submission folder.
