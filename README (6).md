# Stage 3 — Functional Exemplar

## Purpose

This stage represents a substantially developed website ready for testing, evaluation and learner adaptation.

## Expected development

- refined responsive design
- purposeful JavaScript rather than decorative scripting
- usable form controls and validation where appropriate
- accessible gallery/media treatment
- clear hover/focus/active states
- improved content and calls to action
- testing against client, audience and technical requirements
- documented defects and improvements

## Important

This is still an **exemplar**, not the answer to an assignment. Learners should adapt it to their interpretation of the client brief and provide evidence of their own planning, development, testing and refinement.
