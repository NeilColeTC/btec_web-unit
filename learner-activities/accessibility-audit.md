# Accessibility Audit Activity

## Purpose

Accessibility should be considered throughout development rather than added at the end. Audit the Hot Wheels exemplar and decide where it succeeds and where it could be improved.

## Audit checklist

Investigate the Stage 3 website and record evidence for each area.

## Practical tests

Carry out at least these tests:

1. Navigate the site using only the keyboard.
2. Zoom the browser to 200% and inspect the pages.
3. Resize the viewport to a narrow mobile width.
4. Disable images and consider whether the remaining text communicates their purpose.
5. Disable JavaScript and identify what remains accessible.
6. Inspect the form using browser accessibility/developer tools where available.

## Evaluation

Identify:

- three accessibility decisions that are already effective
- two improvements you would prioritise
- one accessibility issue that could particularly affect a specific user group

Explain why each matters rather than simply listing features.

## Apply the learning

Write five accessibility checks that you would include in the test plan for a new website. These should be applicable to your own design rather than copied blindly from Hot Wheels.
