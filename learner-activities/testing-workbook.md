# Website Testing Workbook

## Purpose

Testing should demonstrate that a website has been checked systematically against requirements and that problems lead to improvements and retesting.

Use this structure to practise on the Hot Wheels exemplar. For assessed work, create tests appropriate to your own requirements and implementation.

## Evaluation prompts

After testing, answer:

1. Which tests provided the most useful evidence and why?
2. Did any test reveal an unexpected problem?
3. How did testing influence a development decision?
4. What would you test differently if you repeated the process?
5. What evidence demonstrates improvement rather than simply claiming that the site was tested?
