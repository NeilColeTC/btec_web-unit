# Performance and Image Optimisation Investigation

## Purpose

A website can appear correct while still being inefficient. This activity investigates the relationship between asset choices, page weight and user experience.

The exemplar images are intentionally useful material for investigating optimisation.

## Baseline investigation

1. Record the file size and dimensions of each image used by the exemplar.
2. Use browser developer tools to inspect the Network panel while loading a page.
3. Record the total transferred data and identify the largest resources.
4. Consider how the experience might differ on a slow connection or mobile data plan.

## Optimisation experiment

Create copies of the images outside the exemplar and experiment with one or more of:

- reducing pixel dimensions
- compression
- JPEG where suitable
- WebP or another modern web format

Do not overwrite the originals until you have measured the comparison.

## Evaluate

1. Which optimisation produced the greatest saving?
2. Was there a noticeable loss of quality?
3. Why is the smallest possible file not automatically the best choice?
4. How could oversized images affect users differently?
5. What other website resources could affect performance besides images?

## Development decision

Write a short recommendation for how you would prepare imagery for a new website. Include the trade-off between visual quality, dimensions, format and download size.
