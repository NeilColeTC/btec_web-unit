# Independent Extension Challenges

These challenges intentionally provide requirements rather than finished solutions. Choose techniques appropriate to the problem and be prepared to justify your decisions.

## Challenge 1 — Active navigation state

Help users identify which page they are currently viewing.

Requirements:

- the current page should be visually distinguishable in the navigation
- the solution should remain accessible
- avoid manually creating five completely different navigation structures

Explain whether you solved this primarily with HTML, CSS, JavaScript or a combination.

## Challenge 2 — Character guidance

Improve the contact form so users receive useful guidance about message length.

Decide:

- whether a maximum length is appropriate
- whether a live character count adds value
- what should happen when JavaScript is unavailable

## Challenge 3 — Reduced motion

Investigate the `prefers-reduced-motion` media feature and decide whether any exemplar behaviour should respond to it.

Implement an appropriate improvement and explain the accessibility rationale.

## Challenge 4 — Responsive images

Research `srcset`, `sizes` or the `<picture>` element. Create a small experiment showing how a browser can choose between image resources.

Explain when this would be worthwhile rather than adding it to every image automatically.

## Challenge 5 — User feedback

Choose one interactive feature and improve the feedback users receive after an action.

Examples could include form submission simulation, theme changes or navigation state, but your implementation should be your own.

## Challenge 6 — New client, same technique

Choose one technique demonstrated by Hot Wheels and implement it in a completely different mini-site with different content, structure and visual design.

The purpose is to demonstrate that you understand the technique independently of the exemplar.

## Evidence for an extension

For any challenge you complete, record:

1. the problem or requirement
2. alternatives considered
3. your chosen approach and justification
4. implementation evidence
5. testing evidence
6. one improvement you would make with more time
